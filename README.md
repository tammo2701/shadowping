# ShadowPing

ShadowPing is a GPS-based multiplayer chase game for small groups. Create a private lobby, invite friends, then play as a hunter or runner. The web app works in a modern mobile or desktop browser and can be installed as a PWA. An Android app is also available.

## Play

- Web app: <https://shadowping.pages.dev>
- Android download: <https://shadowping.pages.dev/shadowping.apk>
- In-app privacy notice: <https://shadowping.pages.dev/datenschutz>
- Data handling and security notes: [SECURITY.md](SECURITY.md)
- Support and account deletion requests: <mailto:gps.shadowping@gmail.com>

Location access is required for live gameplay. Camera access is optional and is used for scanning capture codes. Notifications are optional; browser and operating-system support varies. The app asks for these permissions in context.

## Features

- Private lobbies with invite codes and friend invitations
- Hunter and runner roles, teams, configurable play areas, and short-range games
- Live positions during a match, plus match results and location replay data
- Friend requests, lobby status, and in-game event updates
- German and English interface, light and dark themes, and installable PWA support

## This repository

This repository is the **deployment output**, not the application source. It contains the production files generated by Vite from a separate private source checkout. The React source, database schema, Supabase policies, and build configuration are not included here.

Cloudflare Pages serves the contents of this repository's `master` branch at <https://shadowping.pages.dev>. To change the app, update the source project, create a production build, and commit the resulting deployment files here.

Typical contents:

- `index.html`, `assets/` — app entry point and generated bundles
- `manifest.json`, `sw.js`, app icons — PWA metadata, offline shell, and notifications
- `_headers`, `_redirects`, `robots.txt`, `sitemap.xml` — hosting and crawler configuration
- `shadowping.apk` — Android download distributed with the web app
- `README.md`, `SECURITY.md` — project and data-handling documentation

## Data and security

The app sends account and gameplay data to Supabase. During an active match, GPS fixes are sent as a current position and as location-history records used by the results view. This source snapshot does not define automatic cleanup for that history. See [SECURITY.md](SECURITY.md) for the data flow, storage, retention caveats, and vulnerability-reporting contact. The in-app notice is at <https://shadowping.pages.dev/datenschutz>.

The browser build contains a Supabase publishable/anon key because it is a client-side app. That key is not an admin credential; authorization must be enforced by the Supabase project's access policies. This deployment repository does not contain those policies, so it cannot establish whether the live database configuration is correct.
